# V4.11 Readability Refined

## Scope
Presentation-only refinement. Business logic, API routes, database schema, import flow and modules remain unchanged.

## Typography
- Chinese/body tracking reset to normal; negative tracking remains only on large headings and KPI numerals.
- Main body/table text: 14px.
- Navigation: 13–13.5px.
- KPI labels: 13.25–13.5px.
- Supporting text: 12–12.75px.
- Chart axes: 11.5px; legends: 12px.
- Legacy 7–10px UI fragments are explicitly protected and enlarged.
- Tabular numerals are enabled for financial/KPI values.

## Color
- Neutral cool-gray canvas with white surfaces.
- Primary text #17212B.
- Secondary text #334155.
- Tertiary text #536273.
- Supporting text #5F6B7A.
- Primary action #1F5F78.
- Semantic colors use dark foreground + light tint rather than saturated fills.

## Layout rhythm
- Main gaps converge around 16/18/20/22/28/32px.
- Cards use 18–22px radius and restrained shadows.
- Table row height remains 56px in comfortable mode and 49px in compact mode.
- Hover/selected states rely on surface and border luminance changes rather than decorative color.
